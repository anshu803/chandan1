MT Manager:
1. Open this folder.
2. Open bot.py with the text editor.
3. Install dependencies with:
   pip install -U -r requirements.txt

Render:
Use the folder files in a GitHub repository.
Create a Background Worker.
Start command: python bot.py
Set BOT_TOKEN and GEMINI_API_KEY as Render Environment Variables.

Never put real API keys in a public repository.
